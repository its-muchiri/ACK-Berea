1. Creative Direction: The Style Fusion

The site blends five aesthetics into one coherent language, each doing a specific job rather than fighting for attention:

Style	Role in the design
Bauhaus	The skeleton. Strict grid, geometric shapes (circles, triangles, bars), primary color blocking, functional layout logic. Governs structure on every page.
Editorial	The voice. Magazine-style typography, generous whitespace, pull quotes, asymmetric text/image pairings, numbered sections. Governs how content is read.
Reeded glass	The texture. Frosted/fluted vertical-line glass panels used for overlays, nav bars, cards, and section dividers — evokes a modern chapel window without being literal stained glass.
Chromatic gradient	The light. Soft holographic/prism gradients (used behind reeded glass or in hero backgrounds) suggesting light through glass — ties the "glass" and "color" motifs together.
Regency	The warmth and reverence. Fine serif display type, symmetric ornamental dividers, jewel-tone accents (deep emerald, sapphire, burgundy, gold), subtle arch/fan motifs — used sparingly on emotionally weighty pages (About, Leadership, Give).

Guiding principle: Bauhaus grid + Editorial typography = the backbone used everywhere. Reeded glass + chromatic gradient = the signature visual texture (hero sections, nav, cards). Regency = a seasoning, not a base — used on 3–4 pages only so it reads as intentional elegance, not clutter.

2. Global Design System
Color Palette
Base neutrals: warm off-white (
#F7F5F1), soft charcoal (
#22201D), stone grey (
#B8B2A8)
Bauhaus primaries: cobalt blue (
#1B4CE0), mustard yellow (
#E8A93B), brick red (
#C4432B) — used as geometric accents, buttons, tags
Regency jewel tones: deep emerald (
#0F5C42), sapphire (
#1E3A6D), burgundy (
#6B1E2B), antique gold (
#C9A24B) — used on About, Leadership, Give pages
Chromatic gradient: prism gradient moving cobalt → violet → mustard → soft pink, low-opacity, used behind glass panels
Glass tint: white at 12–20% opacity with heavy blur (24–40px) simulating reeded/fluted glass
Typography
Display/Headlines (Regency-Editorial hybrid): a high-contrast serif (e.g., Canela, Fraunces, or GT Sectra) — large scale, tight tracking, used for hero statements and section titles
Body/UI (Bauhaus-Editorial hybrid): a geometric grotesk sans (e.g., Neue Haas Grotesk, Söhne, or Inter) — used for nav, body copy, forms, buttons
Accent/Numerals (Bauhaus): a mono or geometric numeral style for dates, service times, step numbers ("01 / 02 / 03")
Grid & Spacing
12-column Bauhaus grid on desktop, 4-column on mobile
Generous editorial margins (min 24px mobile, 80px+ desktop)
Section rhythm: alternate full-bleed color/gradient blocks with white/neutral breathing-room sections
Signature Components
Reeded glass nav bar — sticky, frosted with vertical fluted-line texture, becomes more opaque on scroll
Glass cards — used for sermon cards, event cards, staff cards; fluted edge, soft gradient glow behind
Bauhaus geometric dividers — circles/bars/triangles used as section breaks instead of plain lines
Regency ornamental rule — thin gold double-line divider with a small centered motif, used only on About/Leadership/Give
Gradient-glass hero bands — full-width hero sections combining chromatic gradient background + reeded glass overlay panel holding the headline/CTA
3. Mobile-First Requirements (priority #1)
Design mobile frames first (375×812 baseline), then scale up to tablet/desktop
Sticky bottom nav or sticky top glass bar with max 4–5 icons: Home, Plan Visit, Give, Watch, Menu
Minimum 44×44px tap targets for all buttons/links
Hero sections: headline + service time + one CTA button visible without scrolling
Collapse multi-column editorial layouts into single-column stacked reading order on mobile — but preserve the asymmetry (offset images, pull quotes) rather than flattening everything to center-aligned
Glass/gradient effects simplified on mobile (lighter blur radius) for performance
Forms (Prayer Request, Contact, Volunteer) use large single-column fields, native input types, and sticky "Submit" button
Livestream and sermon video players must be full-width, tap-to-play, with thumbnail poster frames (no autoplay audio)
