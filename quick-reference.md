# Quick Reference: ACK Berea Questionnaire

## Website Features to Test
Based on the website scrape, these are the key features to reference in the questionnaire:

1. **Service Times:** Sunday 8:00 AM & 10:45 AM (visible on homepage)
2. **Bible Search:** "Search the Bible →" feature on homepage
3. **Give Page:** Accessible from main navigation
4. **Contact Forms:** Prayer request, volunteer sign-up, contact forms
5. **Sermons:** Video sermons section
6. **Events:** Upcoming gatherings section

## Key Questions to Watch

### Most Critical Question
**Q7 (Form Submission):** This tests a known gap - several forms may not actually submit properly. A spike in "wasn't sure if it worked" confirms this is a real problem.

### Usability Metrics
- **Q5-Q7:** Task completion rates
- **Q8:** Mobile performance perception
- **Q15-Q18:** Mini-SUS scores (aim for 3.5+ average)

### Path 3: No M-Pesa experience

### Path 4: Full journey
- Q1 → Q2 → Q3-Q9 → Q10 (Yes) → Q11 → Q12-Q14 → Q15-Q18
